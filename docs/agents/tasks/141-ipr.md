## Report
- Interactive Render is an optional viewport-area tab. It shares the Picture Viewer's
  scene snapshot adapter but limits work to a 512-pixel edge, 16 spp and 16-pixel tiles.
  Tile updates are displayed before the final image and never enter still history.
- Scene/frame changes drop the display buffer immediately, request cancellation,
  and replace any pending snapshot. The next generation starts as soon as the old
  engine returns; hidden tabs and Stop cancel rendering.
- The injected engine test emits a tile, accepts a cube width edit, checks cancellation
  and a restart with changed geometry within 100 ms, then verifies that a late tile
  from the old render did not get through. The bound is for the stub integration,
  not a wall-time guarantee for arbitrary CPU geometry or shading workloads.
- Files: RENDER §R18, UI `interactive_render`, shared snapshot preparation,
  app/dock wiring and `crates/ui/tests/interactive_render.rs`.
