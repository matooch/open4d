## Where it lives
Create > Spline > Arc / Circle / Helix / n-Side / Rectangle / Star / Text / Vectorizer /
4-Side / Cissoid / Cogwheel / Cycloid / Formula / Flower / Profile (plus Empty Spline,

## Result of the export probe (the main finding)

**Splines do not export to OBJ at all.** A default Circle spline exported alone gives a
file holding only the header comment (`# WaveFront *.obj file (generated by CINEMA 4D)`,
51 bytes): no `v`, `l` or `p` records. Making it editable first (Mesh > Conversion >
Make Editable; it becomes an object named "Circle" of type Spline, with Type = Bezier,
Close Spline on, Intermediate Points = Adaptive, Angle 5°) gives the same empty file.

Consequence for the other forms: spline inputs cannot be given as `input.obj`; they are
recorded by their parameters in `[params.input]` (type, radius/width/height, plane,
intermediate points, position), and the generator results (extrude, lathe, loft, sweep)
reveal the sampled spline points indirectly.

Only one case is kept (`circle`, an empty mesh, so the empty-export behaviour is
regression-tested). The other listed rows (circle-radius, rectangle, rectangle-size,
helix, intermediate) would all be empty files, so they were **skipped**; their
parameters are recorded below instead.

## Behaviour notes
- Which parameters are greyed out or hidden by others: Number is active only for
  Natural/Uniform, Angle only for Adaptive/Subdivided, Maximum Length only for
  Subdivided; Radius Y needs Ellipse, Inner Radius needs Ring; the Rectangle's Radius
  needs Rounding.
- Anything surprising: the OBJ exporter skips spline objects entirely, parametric or
  editable.
